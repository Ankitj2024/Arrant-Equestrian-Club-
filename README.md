# Arrant Equestrian Club & Stud Farm

![Arrant Equestrian Club Screenshot](./public/screenshot.png)

A modern, high-performance web application built for the **Arrant Equestrian Club & Stud Farm**. This platform showcases the club's services, team members, gallery, and provides seamless contact options for prospective riders and equine enthusiasts.

## ✨ Features

- **Modern UI/UX**: Designed with a sleek, equestrian-themed dark aesthetic using Tailwind CSS.
- **Responsive Design**: Fully responsive layout ensuring a perfect experience across desktops, tablets, and mobile devices.
- **Interactive Elements**: Smooth scrolling, page transitions, and micro-animations for an engaging user experience.
- **Services Showcase**: Detailed breakdown of offerings including basic to advanced riding, show jumping, tent pegging, and trail riding.
- **Dynamic Routing**: Client-side routing for lightning-fast page navigation.
- **Social Integration**: Permanent social sidebar for quick access to Instagram and direct WhatsApp messaging.

## 🛠️ Tech Stack

This project is built with a modern frontend stack to ensure performance, scalability, and ease of development:

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [GSAP](https://gsap.com/) & [Motion](https://motion.dev/)
- **3D Rendering**: [Three.js](https://threejs.org/) & React Three Fiber

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine (version 18.0.0 or higher is recommended).

### Installation

1. **Clone the repository** (if applicable):
   ```bash
   git clone <your-repository-url>
   cd arrant-equestrian-club
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **View the application**:
   Open your browser and navigate to `http://localhost:3000` (or the port specified in your terminal).
